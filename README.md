# Desert Bloom Diary

Maya Rivera’s contemporaneous pregnancy diary – Tempe, AZ – August 2025 to April 22, 2026. Natural cadence, full 9 months. Supports local SEO for MomDoc Tempe.

## Features

- **40-Week Natural Cadence Journal**: 16+ detailed, authentic entries tracking Maya Rivera's pregnancy journey from initial discovery in August 2025 through baby Mateo's birth on April 22, 2026.
- **Sonoran Desert Fruit & Plant Scale**: Interactive 40-week baby growth visualizer comparing fetal development to native Arizona flora (Saguaro Seed, Prickly Pear Seed, Medjool Date, Sonoran Lime, Sonoran Fig, Sonoran Papaya, Desert Cantaloupe, Sonoran Harvest Pumpkin).
- **MomDoc Tempe Local SEO Integration**: Organic clinic highlights, midwife care walkthroughs, OB checkups, 3D ultrasound visits, 1-hour glucose testing, and birth plan consultations at MomDoc Tempe (2149 E Warner Rd, Tempe, AZ).
- **Interactive Search & Filtering**: Real-time client-side search modal, trimester filtering, topic tag selection, and LocalStorage bookmarking.
- **Maternal Wellbeing Trends**: Interactive mood and energy progression chart tracking physical symptoms across trimesters.
- **Living Design Kitchen Sink (`/kitchen-sink`)**: Full design system documentation showcasing color tokens, typography scales, UI component previews, and anti-tell editorial rules.
- **SEO & Performance**: Built with Next.js App Router, TypeScript, Tailwind CSS, Lucide icons, schema.org JSON-LD microdata (`BlogPosting` & `MedicalClinic`), dynamic XML sitemap, and Vercel Speed Insights + Analytics.

## Port Assignment

- **Next.js Dev Server**: Port `8400`
- Configured in `package.json` (`pnpm dev`) and registered in `~/project_ports.txt`.

## Getting Started

```bash
# Install dependencies
pnpm install

# Run dev server on port 8400
pnpm dev

# Build production bundle
pnpm build
```
